# Changelog

## 0.3.0
- Added Bambu Lab local MQTT integration alongside Klipper / Moonraker
- Added `printboard-server` (background polling + Discord/Telegram webhooks + WebGUI) and `printboard-client`
- Redesigned UI with `Obsidian Cyber`, `Graphite Studio`, and `Daylight Clean` themes, radial gauges, and live temperature sparklines
- Added Print Queue batch dispatcher, Maintenance interval tracker, and `Ctrl+K` Command Palette
- Complete Spoolman spool, filament, and vendor management
- Persistent cookies in the built-in 3D model browser

## 0.2.0
- Telegram / Discord notifications, statistics from Moonraker history, cost calculator, Spoolman spools
- Opt-in control: pause/resume/cancel, temperature, fan, macros, G-code upload
- Model library with 3MF thumbnails and search, autostart

## 0.1.0
- Printer management, dynamic Moonraker queries, overview + detail, camera, model browser
